##  📝Project Overview

This project documents my cybersecurity lab setup as part of the  Cybersecurity Internship.

The main objective was to create a virtual cybersecurity lab using Oracle VirtualBox and Kali Linux.

## 🛠️ Tools and Technologies Used

* Oracle VirtualBox 7.2.22
* Kali Linux 2026.3
* Windows 11
* 7-Zip

## ✅Tasks Completed


### Task 1: Install VirtualBox

Installed Oracle VirtualBox to create and manage virtual machines.

### Task 2: Download Kali Linux

Downloaded the Kali Linux VirtualBox image and extracted the installation files.

### Task 3: Import Kali Linux

Added the Kali Linux virtual machine to Oracle VirtualBox.

### Task 4: Configure NAT Network

Created a NAT Network with the following configuration:

* Network: 10.0.0.0/24
* Gateway: 10.0.0.1
* DHCP: Enabled

### Task 5: Configure Virtual Machine

Configured the Kali Linux virtual machine with:

* RAM: 2048 MB
* Processors: 2
* Network Adapter: NAT Network
